# Checkmate — Java Chess Engine

Projeto de estudo para desenvolver uma engine de xadrez em Java, com foco em programação orientada a objetos e modelagem de regras.

## Objetivo
Representar o tabuleiro e as peças, implementar movimentações e evoluir gradualmente para a validação das regras do jogo.

## Escopo planejado
- Tabuleiro 8 × 8 e posições
- Modelagem de peças e movimentos
- Validação de movimentos e bloqueios
- Controle de turnos
- Detecção de xeque e xeque-mate (etapas futuras)

> Projeto em desenvolvimento. Os itens acima descrevem o escopo, não funcionalidades necessariamente concluídas.

## Tecnologias
- Java
- Maven
- Git e GitHub

## Aprendizados
Encapsulamento, composição, responsabilidades de classes, estruturas de dados e lógica de regras.
